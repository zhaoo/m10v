# GR III 单张半格

用户将成片方式和合理交互交由实现方推荐；本次选择单张竖向 3:4 半格，每次快门独立保存，复用现有画幅菜单、原生裁切及回放。双张拼接需要额外的暂存、取消、断电恢复和两次曝光状态，本次不采用。纯取景辅助线不能交付半格成片，也不采用。

- 机型：GR III 官方 2.10；初始基线 `314ccc2bbf908fb4310a37a3f5b052e99e8aac0e`；交付前整合最新 main `38a847b5871e2441a7934fafd38dcee50d4faef4`。
- 菜单在原有 3:2 / 1:1 / 4:3 / 16:9 / XPan / 6x7 后追加 `Half 3:4`，私有身份 6，旧身份不变。相机横持得到竖构图，转动相机沿用原厂方向元数据。
- 中心裁切：最大 JPEG 2992×4000（16 像素硬件对齐），其他画质为 2400×3200、1680×2240、960×1280；蒙版显示相同范围。35/50mm 及连续焦距采用同一冻结几何规则。
- 原生 ISP/裁切链路，不增加 CPU 整图处理或跨照片缓存；JPEG、缩略图、回放和 DNG 默认裁切须保持身份与构图。RAW 感光像素不改。
- 关闭方式：在原有画幅菜单切回任意其他比例；快门、Fn、胶卷、水印、HDF、存档 ABI 和全部旧画幅语义保留。
- GR IIIx 编译关闭半格入口，保持其现有六个画幅（包括16:9）行为；共享接口仍须做离线回归。GR IV 不受影响。
- 交付可识别 GR III 测试包、配置和源码指纹、官方固件及产物 SHA-256、安装/恢复说明；设备验收前不推送或发布。
- 离线证据不能证明真实像素、AF、回放或拍摄性能，测试包明确等待用户实机验证。

整合说明：保留最新main的边框能力、拍摄/回放修复及16:9菜单恢复；半格是第七项，IIIx仍为六项。最终交付r2重新构建、重新验收，不沿用r1的产物身份。
