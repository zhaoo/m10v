# 撕纸叠映 · GR III ISP 测试版设计

基线：M10V develop/main 9796cc688342abb7bccd6e8ab3daa6af97e753eb；GRemote develop/main 7fa117d05aa395d601cdf9c65701ddddb709910e。线上 M10V 已只读核对为同一提交。用户要求继续完善方案并开发新版本，按上一轮建议选择自拍轮廓、再拍素材的两次拍摄流程。

## 目标与边界

功能名「撕纸叠映」。先拍白底暗色撕纸，再拍实景；第二张的照片内容出现在暗色轮廓里，亮背景变白。CPU 只操作元数据、少量曲线、任务和内存所有权；相机上的轮廓转换、像素复制和混合全部调用原厂 ISP/IIP。禁止原厂多重曝光的 CPU NEON、CPU LUT、CPU 蒙版和手机合成。JPEG 成片保留拍摄尺寸，RAW 像素不修改。首版只支持 GR III 2.10，其他固件/机型不开放此功能；现有其他功能保持。

没有相机实测，不声明颜色/性能/兼容性通过。交付有明确身份的实验测试包，不推送、部署或刷卡。

## 已排除与采用路线

1. 原厂多重曝光：原厂 MultiBlendProcess 0x53504e44，及 0x53504c68/0x5350504c/0x535050f4 存在逐像素 NEON，违反用户要求，排除。
2. 内置撕纸模板单拍：可另作后续预设，本轮不替换用户视频中的自定义轮廓流程。
3. 采用独立两拍亮度蒙版：复用原厂 Granulation 的 Loader/LUT/Blend/Store；关闭原厂 RNG。源与目标首平面可独立绑定，第二平面不被该原语读取。第一张由相同的上下端点曲线生成私有蒙版，第二张分别处理 Y 和 UV。

原厂 RTOS SHA256 8a4eafcad2716e0b21e9909264e1242e534f0e39e05cba82a53546ceb4070b67。单平面 ABI 与 NEON 证据随研究探针存档；硬件 alpha 公式和色边仍须实拍。首版仅接纳 YC422，避免将 NV12 的跳行近似当作正确色度降采样。YC422 的交错色度共享邻接亮度权重可能产生窄彩边，测试包中明确列为图像验收项。

## 所有权与执行

在已有 TopMenu 分配的末尾增加独立 0x100 字节会话，起点 0x6d00；分配增长到 0x6e00。启动时从原厂池预留 align64(6144)*4096+63 字节，仅保留一个 Y 平面，不保留 RAW 或借来的 recipe 像素。取消、完成及销毁在真实硬件完成且无执行 lease 后释放准确的原厂 token。普通关闭路径不分配、不读写像素。

recipe 的已有 ISP tail 后增加独立 32 字节撕纸快照：magic、recipe、SI、会话 generation、phase、UI owner、result、completion。真实投递处冻结，仅允许一个 pending recipe；已排队照片不受后来 UI 改动影响。额外并发曝光拒绝参与本次合成，并把会话标记失败，保留普通原图，不静默生成假合成。执行在原厂空间阶段结束后、JPEG 编码前，使用该阶段原生 context；编码入口检查本张结果，不能伪造完成。阶段失配/取消/尺寸或方向变化在任何新像素工作前拒绝；已提交工作必须等待真实完成，禁止超时后回退或释放 DMA 缓冲。

轮廓 LUT：Y<=48 为0，Y>=208 为255，中间线性过渡；上下端点相同，生成不依赖目标旧值。第二张 Y 上端点255、下端点identity，UV 上端点128、下端点identity；蒙版作为权重。此数学输出是待设备确认的候选，不声称模型即真实输出。每个成功图执行后才置本张完成字段。

## 界面与协议

机身「效果 → 撕纸叠映」，独立子页显示当前阶段以及开始/重新开始、取消；扩展原有四行 root 为可滚动四行窗口，保留原资源编号，在1217后追加中文。GRemote「相机 → 扩展 → 功能 → 撕纸叠映」启动，拍摄页显示阶段及两次拍摄提示。始终使用现有独立对焦和快门，不自动触发快门，不以拍照作对焦回退。

复用现有签名扩展事务及 CAS/receipt/去重：增加 runtime 字段 id24 `tornSession`，读值0关闭、1待拍轮廓、2待拍素材、3已完成、4失败。写值仅0取消或1开始/重新开始，2..4不可写。新 contract hash；App 保留此前三个 hash，旧固件不能收到新字段。该字段不写 journal。快照 revision 需纳入会话 generation，防止相同阶段重新启动后的 ABA。相机 busy/已提交不确定事务时不可启动或取消。断线后只读核对，不自动重放动作。开始时拒绝 Half、非单拍、HDR、Charmera、像素世界等不受本路线支持的配置；排队后再次以本张 SI 校验。

预览只显示原生取景与阶段提示，不生成软件合成。轮廓原图按现有拍摄方式保存；素材拍摄成功后保存合成 JPEG。完成不是 SD 保存成功的独立证明，App 文案不夸大该阶段。
