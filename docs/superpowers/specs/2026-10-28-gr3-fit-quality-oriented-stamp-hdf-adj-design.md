## 1. LUT 拟合质量控制与报告

### 数据与算法

保留 CUBE/XMP 的现有导入入口及 tone/gamut 选择合同。统一报告基于 **最终可编码的矩阵和曲线**：先量化矩阵、压缩/展开实际使用的曲线节点，再运行 III/IIIx 对应模型；不使用未量化浮点参数的误差替代产物误差。拟合模型必须标明 Standard 显示域近似，不宣称恢复原始 RAW 或精确重现 Lightroom 相机配置文件。

结合 Darkslide 的矩阵/曲线表达范围检查、可解释的越界原因，以及 GRMod 的独立验证样本、灰阶与肤色保护、黑白/带色黑白专项拟合。候选优化只有在独立验证上改善整体且不恶化灰阶/肤色约束时才被接受，否则保留基准候选并报告原因。

训练集和验证集固定且互不相同；包含 RGB 空间覆盖、灰阶、肤色、饱和色。固定采样版本、输入域、白点和色差算法；不能把别人的实拍色差数字填入本次报告。所有质量计算在电脑端完成，不进入拍摄任务或逐像素相机 CPU 调色路径。

### 误差报告

网页可查看每种方案，并下载 JSON 报告。至少记录：

- 输入 SHA256、文件类型、目标机型/官方固件身份、拟合器版本与来源、采样版本、最终参数 SHA256。
- 独立验证集 CIEDE2000 的平均值、P95、最大值，以及灰阶、肤色、饱和色分组指标和样本数。
- 最终矩阵/曲线范围检查、曲线端点/单调性、量化/节点重建误差及越界/剪裁的明确定义。
- 所选候选、其他候选摘要、是否接受优化及拒绝原因；XMP 的不支持项和未重建基底信息。
- `camera_verified:false`，并清楚说明这些数值是目标 LUT 与软件相机模型的近似误差，不是实拍准确度。

硬件不可编码、非有限值或协议越界必须拒绝导出。一般高色差给出质量提示，不凭一个任意平均误差阈值宣称无法使用。质量等级阈值/约束独立版本化，具体数值由实现者结合现有模型和回归样本确定并记录。

超出可表达范围时，可提供明确的“生成可表达近似方案”：调整曲线端点/向中性映射收敛，保留原输入，不静默夹值或覆盖。近似方案重新产生参数和完整报告，区分“近似结果对原目标的误差”与“相机模型对近似目标的误差”；由用户显式选择后保存。保留源 LUT 身份和变化程度。

报告随所选方案进入配置/构建记录；后端验证其与实际参数哈希绑定，不能靠前端传入 writable=true 绕过参数合法性。新增元数据不得破坏旧配方导入、旧配置、撤销/重做或取消拟合。原 SD 原始 LUT 路径保留既有行为，本轮不自动改变其存储 ABI 或宣称完成迁移。

## 2. 竖拍水印自动旋转

默认自动跟随方向；方向未知按原横向行为处理。日期、日期时间和胶卷名使用同一变换，四角定义为照片按 EXIF 方向显示后的四角。

在已核验的本张曝光信息入口获取方向，并写入本张 recipe 所属空间；按官方 EXIF 的规则归一为 0/90/180/270 度。后续 UI 转动、换卷或排队照片不能修改已曝光照片的水印。精确字段/入口先用 III/IIIx 官方代码和原厂读写链验证，不能仅引用上游注释或读取编码时的全局姿态。

排版在逻辑画布上完成，再把字形坐标映射到原 Y/C 平面；不旋转整幅图像、不分配整图缓冲、不改变 EXIF/RAW 像素。保留现有字形、颜色、日期格式、字号缩放、双行右对齐和小图跳过规则；处理 Y/C 采样对齐与边界。水印关闭时不新增像素工作。新逐张字段与 HDF/RAW lifetime/color owner 尾部空间必须有静态尺寸和构建检查，不能偷用尚未证明空闲的 reserved 字节。

## 3. HDF 独立 ADJ 选项

在 ADJ 模式设置列表新增“HDF 模拟”，四档关闭/弱/中/强；用户自行放进五个 ADJ 槽之一。已有槽设置不自动重排。功能生效与是否仍占 ADJ 槽无关，MENU 与 ADJ 显示/修改同一 HDF 状态。

复用 `m10v_hdf_load/save` 及已有缓存发布接口，保留写入回读、CRC、失败提示、断电回退；不能在绘制每一项时反复读取存储。已有记录优先，无记录使用构建默认档位。ADJ 改档需遵守原控制器的确认/取消语义，并与 MENU 保持一致，失败不得显示未持久化的值为已保存。

原厂 ADJ 为 20×0x44 的固定表，存在构造长度、函数编号、计数与索引消费者。新增独立函数需整体完成表重定位/所有引用修正、长度和编号边界、五个设置列表及 getter/setter、名称/图标、确认/取消/退出路径；不能只追加一个结构体，也不能借用 0x09、0x13 或任何原厂 ID。

新 ID/持久化选择必须结合 settings load/save/U1–U3 和少功能候选的恢复策略核对；不承诺无条件刷回原厂后保留未知 ID。若原厂路径不能安全表示新增 ID，先完成离线证据并明确阻断交付，不擅自退回占用原厂功能的方案。
