# Marlboro：黑白底色与 800T 红晕

用户已确认 2026-11-05 的东京雨夜模拟观感，并明确同意沿用当前 800T 路径：底色由 ISP 执行，光晕复用已优化的 ARM/NEON 内核。此前纯 ISP 光晕要求已被本次明确授权替代，不扩大为允许 CPU 调色。

- 基线：GitHub main/develop `8fa5f6ff012e5fcb4e90ede13940d8d42f43b267`；部署任务 41973457467 的 DEPLOY_OK 与此 SHA 相同。
- 新增稳定 ID 327、名称 Marlboro，追加在「创意」分组；旧 ID、顺序、十槽与存档 ABI 保持。
- 目标是已批准模拟中的高反差中性黑白底色。以同一浮点参考离线拟合并量化 ISP 参数，记录独立留出误差与来源哈希；机上不执行 LUT、拟合或逐像素去色。
- 光晕与 800T 使用同一个 `m10v_800t_effects`，不复制或调参。默认强度/范围/阈值为 7/7/5，FN 表、滑块范围、保存/重置/失败语义与 800T 一致。底色不同自然会改变光源遮罩，不承诺两张图的遮罩数值相同。
- 关闭光晕及其他附加效果后，真实拍摄投递→冻结→Still Make→完成校验→JPEG 必须无 CPU 像素工作。缺失 ISP 完成时拒绝新卷的 CPU 调色。
- 沿现有 GR III 2.10 / IIIx 1.60 适配器集成；其他版本与机型不得因新 ID 获得额外能力。保留 HDF、边框、水印、RAW、已保存设置与 SD 历史记录。
- 新增资源仅追加：图标 887、名称 1202（1191..1201 仍保留 ADJ 扩展文字）。SD 内置快照使用独立 M10VS84，不占用旧编号。

## Approaches

纯 ISP 空间红晕需要新的硬件图及校准，当前不满足既有算法复用；另写 CPU 黑白/LUT 会违反性能要求。用户选择现有混合路径：新增 ISP 黑白配方，复用 800T 空间阶段与菜单。
