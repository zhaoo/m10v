## RAW 与回放

`scripts/probe_gr3_raw_guides_adj.py` 从两个最终 BIN 回读，执行真实 MakerNote 解析函数。原厂十二款的回放代码和显影 tone 均保留。内联与外置 EXIF SHORT 都能在回放辨认已记录的 800T、蓝凤凰或自定义版本，RAW 显影入口仍把私有值读成原厂 Standard。

| 入口 | 地址 | 证据 |
| --- | --- | --- |
| RAW 文件身份读取 | `0x535bf7a8` | 读取 MakerNote SHORT 后经 `0x535bf7c4` 进入原厂映射，把 tone 字节写入目标 SI 的 `+0x77c` |
| RAW 标签分发 | `0x535eefdc`、`0x53618d74`、`0x5361ef0c` | 两款最终 BIN 上的原调用指令相同 |
| RAW 选项 | `0x53283358`、`0x53283c08` | 执行确认列表 14 或 15 项，转盘 12 种风格 |
| 回放元数据 | `0x535c24ec` | 已有独立私有身份解码，输出旧槽标记或稳定卷标记 |

拍摄中供 MakerNote 写入使用的尾部由专用池租约保护。现有证据只覆盖该池，RAW 文件读取目标必须另行核对所有者和退出时机。拍摄写入和回放已共用 `m10v_recorded_film.h` 的身份约定，覆盖 210 个自定义 ID 的每个编码版本。编码合法与对应版本在卡上可读取是两个条件。

两个候选的 ARM 探针执行 `0x53510830` 和原厂复制函数，源对象恰在未映射页之前结束。复制原厂的 475760 字节，目的端租约的旧身份被清除，代数从 6 递增到 7。

### 原厂显影模型和成片入口

| 阶段 | 双机型入口 | 行为 |
| --- | --- | --- |
| 影像控制和取消 | `0x53283358`、`0x532834d0`、`0x532834f0`、`0x5318a6d0`、`0x53289314` | 14 或 15 行。As Shot 为 enum 0，保留 12 个原厂风格和两个原厂显影设置。选项写入 working SI，取消从对应 DNG 的 input SI 恢复 |
| RAW 预览 | `0x53281978` → `0x534d65c0` → `0x53516b40` | Processing 收到 `0x72c8100d`，从包的 `+0x14` 读取本次 SI。根据预览尺寸和刷新类型分流到模式 9、10 或 11 |
| RAW 另存 JPEG | `0x53281ab8` → `0x534d6ab8` → `0x53516bfc` | 显影确认发送 `0x44411017`。处理服务发 `0x72c8100e`，包的 `+0x10` 是本次 SI，`+0x14` 是请求的保存标记。模式 12 保留此标记至 recipe `+0x3f` |
| DNG 卷身份 | `0x535f1414` → `0x535f2394` → `0x535c24ec`，`0x534eafc8` | 原厂 RICOH MakerNote 解析器的 0x4f 标签复用回放解码，将 M10V 卷身份写到对应 DNG 文件对象的 `+0x220` |
| 批量输入 | `0x5327fc14` → `0x5327f2a0` → `0x534c09b8` → `0x534bf4c0` | 后续文件由 `0x44411019` 按序号重新载入，经同一个文件读取器刷新当前文件的元数据。成功通知 `0x24480219` 后才发出下张保存请求。接下来的 0x820 字节原厂参数复制没有携带卷身份 |
| ISP | `0x5351cfac` → `0x53510800`，`0x5350e624` → `0x5350eb10` → `0x53501d68` | 另存任务复制自己的 SI 到 recipe，预览和另存均调度 stage 0 Still Make。另存继续 BackResize 和 JPEG。RAW 模式已能识别，现有色彩 hook 仍要求拍摄槽的 carrier tone |
| 任务关闭 | `0x4441101a` → `0x534c1bcc` → `0x534bf300` | 原厂关闭和载入失败路径释放当前文件对象及 working SI 并清空指针。下一张载入前需要独立清空上次文件的配方 |

`tests/test_gr3_raw_development_stock.py` 在原厂及两款最终 BIN 中执行列表、确认、取消、每张文件的 As Shot 回读、两类消息打包、Processing 模式选择和 DNG 卷身份到文件对象的复制。卷身份测试覆盖内联、外置 SHORT 及非法标记。外部事件队列、分配器和属性服务由仿真边界替代。

[GRKit](https://github.com/ahonn/grkit/blob/8d24f076333e3e31f1a0ec68a0590f6cada71966/runtime/menu.c#L1057) 的 GR III 参考通过 `0x550662d0` 和 `0x550666e0` 判断显影 UI 模式。M10V 的异步和批量显影需要沿请求传递身份。[gr3-film-mods](https://github.com/idontknownihil/gr3-film-mods/blob/04d5d5dd6e85d80089c6200bd0f0de5fff2d658f/FINDINGS.md#34-playback-raw-development-with-films-fixed-in-v16-2026-10-10-not-yet-camera-tested) 提供了显影列表、参数缓存和 As Shot 的参考，使用固定滤镜枚举。[Ricoh-GRMod](https://github.com/Maxwooow/Ricoh-GRMod/blob/1f4216e4b80d737a3e670c0b6169398f57598b5e/README.md) 提供独立配方和 MakerNote 行为参考，其目标机型为 GR IV。

原厂文件信息的私有 SHORT 只记录卷 ID 或自定义 ID 与版本。历史逐卷参数没有写入该字段。As Shot 使用记录对应的内建默认色彩。缺失、旧槽码和未验证的自定义卷沿用原厂色彩。

| 阶段 | 实际接入 |
| --- | --- |
| 请求 | 原厂预览和保存请求各用一个经过核对的末尾空字传递 As Shot、原厂风格或明确选择的稳定卷 ID。存储任务只读当前文件的元数据。 |

### 回放卷名候选

原厂单张播放的影像控制详情增加一行卷名。只从该照片的 MakerNote 解码，内建卷名随照片切换。旧槽码和无法证明来源的自定义卷显示 `Unknown film`。自定义 ID 和版本可被不同相机各自分配，同名文件存在也不能鉴别照片来源。原厂卷与非法标签隐藏这行。

双机型成品 ARM 检查运行了原厂 MakerNote 读取、控件分配、创建、文字更新、隐藏和析构。包括切图、非详情和非静态路由、外置 SHORT、未知卷、分配失败和原厂控件位置。GR III 核对 297 处原厂补丁，GR IIIx 核对 296 处，两者均仅修改 RTOS。

## 构图与九槽

最终 BIN 的原厂 Grid Style 菜单可选黄金分割和四向螺旋，沿用 DISP 档的网格开关。原厂画布清除后叠加线条并调用一次原子控件绘制。成品仿真覆盖 XPan 蒙版、IIIx 原生宽幅、画布裁切和退出后迟到的更新。

两份成品在 `0x531a425c` 与 `0x531a4264` 分别从控制器的 `+0x184`、`+0x16c` 取图标和格控件，`0x531a42bc` 按五格结束。第 6–9 槽使用独立控件、游标和存档，所有控件创建成功后发布一排九格。成品仿真覆盖 Setup 设置写入、原厂触摸绑定、A/B 暂停、创建失败和全部关闭后的五格。U 档切换和相机 SD 读写仍待真机验收。

两款最终 BIN 各通过 23 项成品测试。另有 17 项构图、九槽及 Setup 组合测试和 24 项逐卷、纯 ISP、GRemote 配置测试通过。两张用户样图在 6000×4000 上分别跑蓝凤凰和 800T，从最终 BIN 提取的 ARM 运行体与已有优化基线对比，两款机型的 Y 和交错 CbCr 均无差异。另跑的旧设置控制器组在候选和 RC2 均有同样的 9 个失败和 2 个错误，旧 ADJ 仿真的代表失败在 RC2 复现。真机屏幕、按键、存片耗时及 RAW 扩展未验收。
