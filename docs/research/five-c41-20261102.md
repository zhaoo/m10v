# Five C41 additions: evidence and limitations

Base: GitHub main and successful production a24ccc2618aff06baf9359808120ce6a4e881ab0. New identities 322..326; existing identities, old LUT/profile values and state ABI retained. User explicitly requested direct release and no full local test suite.

| ID | Stock and primary reference | Use and remaining assumptions |
| --- | --- | --- |
| 322 | [Original HARMAN Phoenix 200, September 2024](https://www.harmanphoto.co.uk/amfile/file/download/file/1963/product/2143/) | High contrast, strong colour, ISO200 daylight/C41, no masking dyes. Independent numerical display design; characteristic chart was not digitized. Distinct from existing Phoenix II. |
| 323 | Kodak ColorPlus 200 | No same-stock official sensitometric publication or digital LUT located in manufacturer searches. Independent warm, restrained display design. Official colour-data requirement is unmet; Gold200/VR200/Kodacolor are not substituted. |
| 324 | [Fujifilm NATURA1600 bulletin 013AR313B](https://asset.fujifilm.com/www/jp/files/2024-04/96b634a89ec6a5abda6b70437f4d75a4/datasheet_natura1600_01.pdf) | Vendored MIT Spectral Film LUT Natura1600 curves with declared daylight5500K/display-sRGB adaptation. RGB spectral reconstruction, inversion and viewing adaptation are assumptions. Upstream borrowed RMS grain data is not used: these colour LUTs bake no grain, MTF or halation. |
| 325 | [Lomography Redscale XR official launch](https://www.lomography.com/magazine/34658-experiment-with-the-new-lomography-redscale-xr-film) | Single authored ISO200 red/orange direction. Does not reproduce the complete ISO12..400 exposure-dependent range; existing HARMAN RED exposure settings are unchanged. |
| 326 | [Agfa standard-film technical brochure F-AF-E6, archived manufacturer PDF](https://125px.com/docs/unsorted/agfa/F-AF-E6_en.pdf) | Original Agfa Vista200, daylight5500K, C41 and EYE VISION colour-fidelity direction. Numerical display design, not digitized curves; neither Vista100 nor later AgfaPhoto Vista Plus/FujiC200. |

No official positive digital LUT was obtained for these five stocks. Numerical coefficients, display adaptation and the result are approximations. Neither film nor camera is calibrated; 100 percent physical-film similarity cannot be established from this evidence.

Offline fit uses one numerical worker, a fixed training seed and a separate 32,768-colour holdout. Errors below compare quantized ISP output with the declared design LUT, not photographs or physical stock:

| Stock | Median DeltaE00 | 95th percentile DeltaE00 | Maximum DeltaE00 |
| --- | ---: | ---: | ---: |
| Phoenix 200 | 0.357 | 1.334 | 4.563 |
| ColorPlus 200 | 0.233 | 0.377 | 0.700 |
| Natura 1600 | 2.838 | 9.666 | 27.402 |
| Redscale XR | 0.498 | 1.067 | 2.529 |
| Vista 200 | 0.376 | 0.643 | 3.488 |

Natura does not pass the existing high-fidelity numerical gate. It remains a limited ISP approximation; the gate is recorded false. The other four pass the design-LUT numerical gate, which is not physical film validation. All camera eligibility fields remain false. No CPU colour fallback was added.

Five new profiles crossed the existing per-module 64KiB limit. C41 read-only data is therefore linked in a separate bounded module; all original relocation, coefficient, input-identity and final-BIN checks remain enabled.

Checks: 14 focused Node tests, 6 C/SD/card tests, source/table/profile/SD readback and changelog guards; one GR III export containing all five additions passed final decoding and 158 hook checks. The real task-producer -> snapshot -> Still Make -> completion -> encoder test passed for all seven C41 IDs at both stages, with 24MP pixels unmapped. This is software evidence, not ISP-hardware or camera-performance validation. Full suite, local three-model build and camera tests were intentionally skipped. Production deployment retains its normal server build checks.

Review fixes: extended initial-state identity/native ownership gates, independent new artwork/resource readback, exact previous-production SD v1/v2 compatibility and source fingerprint coverage. Physical similarity, camera behaviour and deployment are separately reported, not inferred from code review.
