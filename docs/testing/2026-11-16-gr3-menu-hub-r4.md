# GR III 2.10 m10v 菜单 R4 日志测试

使用上次实测的 GR III 2.10 升级流程。升级前先备份原固件、设置、脚本、胶卷库、自定义 LUT 和照片。先将 `04_MENU/SD_ROOT/M10V/MENU.M10` 放到 SD 卡的 `M10V/MENU.M10`，再用 `01_FIRMWARE/SD_ROOT/fwdc239b.bin` 升级。升级后关机移走 BIN，保留菜单资源。R4 固件与菜单资源需成对使用；现有胶卷库可以继续使用。联测 GRemote 时使用包内与固件配套的服务。

1. 从原厂设置打开 m10v。首屏从左到右是设置、胶卷库、效果。向左滑到第二屏，逐一打开说明和打赏，从左上角返回。打赏页分别用支付宝及微信扫码，确认能识别对应收款码。
2. 打开效果，逐一验证 HDF、边框、胶卷印花、暗角、撕纸和 A/B。印花上滑看后四项，下滑回前四项，点选后再按「保存」或实体 OK。仅滑动时已保存值应保持原样；从印花返回直接回效果列表。
3. 在暗角页查看「开关」「强度」。编辑后返回暗角页，再返回效果列表。关闭暗角后保存强度，重新开启应恢复保存的强度。
4. 验证设置下水印及子项、关机图、ADJ 6–9、裁切焦距，确认操作后从正确层级返回。A/B 风格只在对应行显示。原厂画幅、构图线、影像控制、RAW 显影和原厂 ADJ 使用原有入口与界面。逐卷参数仍由 Fn 或 ADJ 进入原厂参数容器，m10v 私有行的数值已加宽和高亮。
5. 正常关机后，回传 SD 卡根目录生成的 `M10VMN0.BIN` 和 `M10VMN1.BIN`。菜单日志中的 340–344 记录 m10v 入口、触屏及资源读取，35–39 记录功能页输入和路由。附上操作顺序和实机照片有助于定位显示问题。

固件摘要与 Build ID 见 `evidence/firmware-receipt.json`。日志分析脚本位于 `tools/read_gr3_debug_log.py`。离线验证已执行固件 ARM、原生位图绘制和包装回读；相机面板上的显示、触屏和二维码扫描待真机验证。
