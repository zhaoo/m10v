## 原厂 ABI 错误与修正

原厂图像描述符的格式字段在偏移0，只占1字节。
536a3d84 的赋值函数使用 LDRB/STRB（536a3d90/536a3dbc），不会复制偏移1..3；
原厂 holder 构造也只对格式写 STRB，不保证其后3字节清零。

原代码在 pipeline_photo 中将整个32位字与1/2比较，导致格式仍为1的合法描述符
（例如格式字 a5a5a501）被拒绝。计划失败后，原厂 worker 可以正常返回，
但新效果没有工作区查询或完成标记；编码入口因此一直等待，与设备日志状态吻合。

r12 只按最低1字节识别格式，并同步修正工作区重叠检查中422/420色度平面的大小判断。
不清零或改写原厂描述符填充，不读取照片像素，不减少完成、归属、容量或释放检查。
仍拒绝不支持的格式；422色度平面的后半部分继续受到完整重叠保护。

相机日志没有记录该格式字原值，不能声称已经采样到相机上的具体填充值。
这是有原厂指令和旧固件复现支持的接口修正，是否完全消除实际回放故障仍需本包真机验证。
