# GR III 2.10 撕纸效果 R8

R8 使用四块错开的纸片轮廓，并通过原厂 IIP 在纸边留出露白的纸芯、在外侧加一圈浅影。相邻两次快门随机使用不同版式。浅影复用现有蒙版缓冲区，增加一次缩放和两次亮度作业。

1. 按原有流程更新本包的 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`。用手机控制时继续使用 GRemote 1.2.10，并使用本包配套的 `02_SERVICE`。
2. 在机身 **效果 → 撕纸效果** 进入子菜单，选 **开** 并按 OK。外层菜单固定显示功能名称。
3. 正常拍一张有颜色和明暗对比的场景，再拍一张检查随机版式。查看纸缝、露白和浅影，以及拍完回到取景的速度。

包内的桌面模拟图是质感参考。机内测试版实现了新轮廓、露白和浅影，微细纤维与底纸颗粒仍属于桌面模拟。成片和耗时待真机复测。有异常时，可回传 JPEG 和 SD 卡根目录实际生成的 `M10VTO0.BIN` 或 `M10VTO1.BIN`。
