# GR III 2.10 莱卡胶卷验证记录

胶卷配置、SD 胶卷库和 GRemote 共用「影像」分类下的四个胶卷身份。331 为 Leica Chrome，332 为 Leica Brass，333 为 Leica Teal，334 为 Leica Classic。GR III 2.10 用同一份量化 ISP 配方处理取景和 JPEG 成片。JPEG 编码入口会检查本张的 ISP 色彩完成记录，缺失时拒绝进入胶卷的 CPU 调色路径。

## 色彩参考

使用 19 组 Leica 官网同场景 Standard / Look 对照图拟合。每款留出一组完整场景，拟合完成后用这些场景选择样本权重。Classic 另用独立 Leica Q3 直出样片核对。Robin Schimko 的 Lightroom 配置对照图用于观察色彩趋势。实际配方、来源摘要、取样方法和误差详见 [色彩拟合记录](../../native/gr3/leica-reference.json)。

| 胶卷 | 官网留出场景 ΔE00 中位数 | ΔE00 P95 |
| --- | ---: | ---: |
| Leica Chrome | 1.17 | 2.93 |
| Leica Brass | 1.94 | 9.19 |
| Leica Teal | 1.31 | 5.05 |
| Leica Classic | 3.26 | 9.30 |

独立 Leica Q3 Classic 对照包含 1,684 个匹配色块，ΔE00 中位数为 2.93，P95 为 6.94。这些结果来自公开图像和 ISP 数学模型。实际 GR III 传感器、白平衡及曝光响应还需真机测量。

## RC1 离线验证

- 固件基于 M10V `824d68f` 和 GRemote `6442da9` 的本地 `develop` 改动。固件诊断标识为 `ba509ea0`，通过 328 个钩子的独立回读验证。合并 8 份字节完全一致的只读彩虹纹理，复核展开后的原纹理 SHA-256，代码与纹理区在排他地址边界相接。
- ARM 模拟的 5 组最终固件用例通过。覆盖四款新效果的真实任务投递、单张快照、取景与 Still Make 系数一致性、无 ISP 完成位时提前拒绝、2400 万像素缓冲区未映射时的成片入口，以及新旧 SD 记录验证。机内胶卷库绘制独立卡面，ADJ 使用通用胶卷图标。
- 74 项 ISP 效果及印花回归、7 项胶卷 Node 回归通过。通过本机 HTTP 核对配置页、胶卷库和导出。历史 SD 测试文件另有 4 项失败，已在原始 `824d68f` 上复现同样的失败。
- GRemote Flutter 731 项通过、3 项跳过，含 4 项相机 C 服务回环验证。Android 单元测试 54 项通过，签名 APK 内置目录与固件和服务一致。

## 真机验证

1. 在网页胶卷配置和胶卷库的「影像」分类核对四款效果。GR III 2.10 机内胶卷库沿用分页列表，四款卡片位于内置胶卷末尾。在机内换卷后核对 GRemote 读回和装卷。使用配套胶卷包，保留旧胶卷库和个人 LUT 的备份。
2. 关闭颗粒、光晕、HDF、水印及撕纸效果，在同场景用相同曝光、白平衡、照片尺寸和 SD 卡分别拍原厂正片、负片与四款莱卡效果。记录切卷后首张、即时回放、返回取景和连续拍摄表现。
3. 每款保留原始 JPEG。优先对比灰阶、肤色、高饱和色以及低光。需要定位成片问题时，按候选的诊断 build ID 关联快照、原生色彩完成位、CPU 残余阶段和 JPEG 保存时间。

## RC2 ADJ 图标修复

RC1 为四款莱卡胶卷返回同一个通用资源 `876`。RC2 为 Chrome、Brass、Teal、Classic 分配独立的 40×40 图标，资源编号为 `891–894`。图标临时缓冲区由原有绘制生命周期管理。对 ISP 曲线改用无损存储，为图标留出固件空间。

ARM 回归覆盖四个 ADJ 资源选择、实际图标展开及退出释放，并核对三个既有胶卷的图标和原始 ISP 曲线系数。最终固件的诊断标识为 `19bc5903`。RC1 随包的 64 条胶卷记录全部通过 RC2 校验，更新固件后可保留现有 RC1 胶卷库。配套 GRemote 同时识别 RC1 和 RC2 的目录身份。相机屏幕实际显示待真机确认。

## RC3 机内卡面

ADJ 的 40×40 图标和机内胶卷库的 128×128 卡片统一使用 **LEICA** 品牌字样、红圆点、米白底和黑色标题。卡面显示 CHROME、BRASS、TEAL、CLASSIC 全名，ADJ 的滤镜名称按可用宽度排版。随包预览使用真实图标像素及胶卷库渲染器，ADJ 图标放大三倍。

RC3 的固件诊断标识为 `cfeab1d0`。已核对 RC2 和 RC3 的 `FILMS.M10` 逐字节一致，GRemote 目录与渲染器摘要一致。ARM 回归逐项核对 ISP 系数和最终固件中的绘制入口。使用 GRemote 连接 RC3 时，可沿用 RC2 的 APK，更新 RC3 随包连接服务。实际 LCD 可读性待真机确认。
