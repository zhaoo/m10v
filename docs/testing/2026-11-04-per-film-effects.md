# 逐卷胶片效果测试候选

仅适用于 GR III 2.10 或 GR IIIx 1.60。按机型选择对应 ZIP，使用已确认的同机型固件流程。保留上一份可用固件、卡上照片、自定义 LUT 和脚本。卡上已有兼容的 `M10V/FILMS.M10` 时可以继续使用。

1. 在 ADJ 选两款已装胶卷并分别按 FN。给其中一款设置颗粒、漏光和模糊，切到另一款后核对它自己的参数。再切回、重启并检查保存结果。
2. 检查普通胶卷的高光溢出和横向拉丝。对 800T 和蓝凤凰分别调整强度、范围和阈值，验证两个专属光晕。取景仍只显示已有实时色彩效果。
3. 分别以横拍、竖拍和倒置验证漏光的位置。随机模式拍多张。检查颗粒的细、中、粗与模糊的轻、中、强，并在 Charmera 和方块世界各拍一组对照。
4. 检查 MENU 效果只提供 HDF 和边框。升级时已启用的旧效果会复制到现有胶卷，已有独立颗粒保留，新装卷默认关闭。旧双侧漏光迁为随机。旧全局存档和旧胶卷存档保留在原位置。
5. 全部关闭后，用同画质、同曝光和同一张卡，对照原厂正片或负片，检查即时回放、相册、单拍和连续三张的恢复。组合效果再检查 RAW+JPEG 和连拍。

GR III GRemote 组合包使用包内匹配的服务和已有的热点连接流程。相机端逐卷效果从 FN 调整。旧全局颗粒、漏光、模糊控件在这份组合包不再对 App 声明可用。

回退时按此前已验证的同机型流程恢复固件和原 SD 文件。此候选把新设置写入 M10V7A/B 存档，旧固件读取原有存档。记录异常前后的机型、固件 SHA-256、操作步骤和照片。

离线验证覆盖封包与回读、GR III 原厂任务入口、逐卷迁移、快照冻结、JPEG 接入和关闭效果时的零像素访问。真机画质、物理 DMA、连拍、回放与性能待验收。
