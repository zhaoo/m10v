# 效果面板诊断 r8

适用：GR III 2.10 / GR IIIx 1.60，分别下载，不可交叉刷入。
基于用户正在测试的 r7；未合并远端 main 后续无关变更，未推送或部署。

本包增加效果入口工厂、页面构造、路由映射、ready 分阶段、enter、按键前后日志。
同时修复已用 ARM 测试复现的问题：首次启动无 ISPFXA/B 设置记录时，构造阶段已发布默认缓存，
再次进入面板刷新却返回 -2，ready 因而返回 0，页面无法打开。
修复仅允许未保存的零代默认缓存重复刷新；已保存/非默认缓存丢失记录仍保留错误保护。
没有修改 ISP 像素处理、图像缓冲或释放逻辑。相机实际入口是否恢复仍待本包验证。

操作与回传：

1. 按包内原有更新流程安装对应机型 BIN，保留 r7 或之前可用的同机型恢复包。
2. 开机进入菜单，选择“效果”，按一次确认，等待约 5 秒。若能打开，按下、确认进入漏光，再返回。
3. 若仍无反应，不连续快速点击；正常返回、关机，等写卡指示停止后取卡。
4. 回传 SD 卡根目录 M10VMN0.BIN、M10VMN1.BIN、M10VIO0.BIN、M10VIO1.BIN（存在的文件都回传），
   并注明机型，以及卡住在“效果”入口还是子项。无需提供照片或设置存档。
5. 若机器无法正常退出，按既有恢复流程处理，避免写卡期间拔卡/断电。
