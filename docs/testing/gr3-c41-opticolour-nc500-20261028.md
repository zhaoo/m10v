## 参考与证据边界

- OptiColour 200：[Optik Oldschool 官方产品资料](https://www.optik-oldschool.com/products/opticolour-200)。ISO 200，日光、C41，强调自然色彩、红绿和肤色；未提供完整测量色表。
- NC500：[Filmotec 官方产品资料](https://filmotec.de/originalwolfen-nc500/)及[技术资料](https://filmotec.de/wp-content/uploads/2023/04/Datenblatt-Wolfen-NC500.pdf)。ISO 400，日光 C41；强调绿色、低饱和暗部与颗粒。技术资料曲线未数字化，不宣称其数字被用作模型系数。

没有找到来源和复用许可都可确认的这两款精确同名社区 LUT。本次依据上述定性约束独立建立显示 RGB 近似模型；全部数值系数均为模型假设，详见 `scripts/build_gr3_c41_reference.py` 与 `native/gr3/c41-reference.json`。不是官方 LUT、实体胶卷测量或相机标定，不承诺 100% 还原。网页与相机都以量化 ISP 近似为默认效果；LUT 仅用于离线参考与网页，不在相机上执行 CPU 调色。
