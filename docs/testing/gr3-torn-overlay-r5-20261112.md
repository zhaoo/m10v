# GR III 2.10 撕纸叠映 R5

参考视频先拍白底上的深色碎纸，再拍实景。白底和纸缝在成片中保持白色，实景只在纸片轮廓内出现。R4 实拍两张均完成原厂 IIP 处理并通过 JPEG 准入。R4 的蒙版在亮度 48 到 208 之间线性过渡，大量中间亮度会让实景半透明地透出。

R5 将蒙版的过渡收窄到亮度 112 到 136，并平滑过渡两端。深色区域对应完整实景，浅色区域对应白底。阈值是针对参考效果的起点，真机成片仍需同条件对照。亮度、色度和蒙版继续由原厂 IIP 处理。

1. 更新本包的 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`。使用 GRemote 时继续用 1.2.9，并使用本包配套的 `02_SERVICE`。
2. 在机身 **效果 → 撕纸叠映** 按 OK。第一张拍白底上的几块深色哑光碎纸，纸片间留白缝，避免阴影穿过白底。第二张拍彩色实景。两张保持同画幅和方向。
3. 检查第二张的白底和纸缝有无残影，纸片内的颜色和纹理是否清楚。如有异常，回传两张 JPEG 和 SD 卡根目录实际生成的 `M10VTO0.BIN` 或 `M10VTO1.BIN`。
