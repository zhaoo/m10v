## 给用户的步骤

本包只需更新 fw/fwdc239b.bin，沿用现有 FILMS.M10 和配置，不复制或删除任何设置文件。

1. 更新完成后，将卡根旧的 M10VAK0.BIN、M10VAK1.BIN 先备份移走；只处理这两个日志文件。
2. 第一轮：普通 ADJ → 影像控制 → 按电源退出。只复现一次。
3. 卡死后（不是更新固件时）断电取卡，**先拷日志，不要先重开相机**。保存到“普通ADJ关机”文件夹。
4. 将该轮日志移走后，再开机测试第二轮：ADJ → DISP 打开 A/B 选卷页，松开按键，再按 DISP 退出。保存到“A-B退出”文件夹。
5. 回传每轮卡根的 **M10VAK0.BIN、M10VAK1.BIN**，有哪个发哪个，并注明哪轮、卡死前画面、是否收镜头。即使日志版没有卡死，也照样回传。无需发送照片或整张卡。

若两个文件都没有生成，直接反馈“没有日志”，不要连续反复复现。每个文件正常为4096字节；短文件也原样保留，双页设计可能仍保住上一页。
