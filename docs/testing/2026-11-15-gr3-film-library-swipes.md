# GR III 2.10 胶卷库测试说明

本候选基于 M10V `c6d776b` 的 `develop`，使用保留现有机内设置的构建配置。GRemote 基线为 `f4d725f`，可使用现有 App。固件、配套服务和胶卷库的哈希见包内 `manifest.json`，日志 Build ID 见 `evidence/firmware-receipt.json` 的 `debug_log.build_id`。

1. 按包内《开始前必读》准备，仅在 GR III 2.10 上验证。先备份现有固件、启动脚本、胶卷库、自定义 LUT 和设置。机内界面验证可保留现有兼容的胶卷库。需要联测 GRemote 时，再按说明使用本包配套的 SD 服务。
2. 打开机身胶卷库。核对右上角的「已选：n/10」、每页两排封面、封面下方的卷名与底部圆点。检查 `Aerochrome`、`LomoChrome Turquoise`、`Classic Negative` 等卷名中大小写是否沿基线排列，及长名称是否完整。若有自定义 LUT，翻到末页检查其名称。
3. 点按一卷已启用的胶卷，确认右上角的黄底黑勾圆标消失、计数减一，黄色边框也消失。点同一卷恢复，确认圆标重新出现、计数加一。点按未聚焦的胶卷时也应直接启停。满十卷时点按未启用的卷，应提示先停用一卷。之后按方向键，确认黄色焦点框重新出现。
4. 左右滑动，检查一次横滑只翻一页。短划、竖滑、点卡片间隙与空白格，以及在首尾页向外滑动，都不应误启停。用方向键和 OK 验证原有启停路径，再检查 MENU 返回和 DISP 回到取景。
5. 做完后正常关机，从 SD 卡根目录复制 `M10VMN0.BIN`、`M10VMN1.BIN`（以实际生成的文件为准）。回传这两份日志，附上出现问题的操作顺序和屏幕照片。

菜单日志事件 `76` 记录起点坐标和胶卷索引。`77` 记录有符号的横向及纵向位移、翻页前后的索引。`78` 记录取消时的触摸事件类型和触点数。`79` 记录点击坐标、目录索引以及启停后的计数与错误码。菜单通道保留有限数量的近期记录，复现后宜直接关机取卡。

本轮检查覆盖主机封面栅格化、GR III 2.10 原厂分发路径的 ARM 模拟、菜单控件描述符和 GRemote 胶卷库页面。机身触控坐标、实际 LCD 合成、翻页响应速度及无线连接仍需真机验证。

R3 字形排查对照了现有字库和同一份 14px Noto Sans Bold。原字库按各字形墨迹的顶部裁齐，R2 卷名光栅逐字从顶部画出。按共同基线恢复纵向偏移后，全部 95 个 ASCII 字形的覆盖像素与原字体参考一致。R3 另放宽六个字母的卷名绘制步进，避免右缘裁切。
