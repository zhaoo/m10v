# GR III 2.10 撕纸叠映 R6

在机身 **效果 → 撕纸叠映** 开启后，正常按一次快门即可。每张从三款碎纸轮廓中随机选一款，相邻两张使用不同轮廓。纸片内保留当张照片，纸片外和纸缝为白色。拍完仍保持开启，随时可从同一菜单关闭。

按原有流程更新 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`。如用手机控制，安装 GRemote 1.2.10 并使用本包配套的 `02_SERVICE`。首次测试建议开启后直接拍两张不同场景，分别检查成片，以及两张的轮廓是否不同。

构建 `198a47de`。三个轮廓在构建时写入固件。拍摄时由原厂 IIP 缩放蒙版并混合亮度、色度。ARM 回归已核对原厂缩放参数、原厂合成作业提交和 JPEG 准入。真机边缘、耗时以及新的临时缓冲区在机身上的可用性待复测。若出图异常，可回传照片和 SD 卡根目录实际生成的 `M10VTO0.BIN`、`M10VTO1.BIN`。
