- 上游明确将模型 ISO 从 800 调整为 **1000** 以补偿观感，本实现保留该选择并在来源报告披露；目录仍显示实体胶片额定 ISO 800。输入为已编码显示 sRGB，光谱升采样无法找回场景原始光谱；曝光和观看色温均设 5500K，EV 补偿 0、不进行额外色罩修正/白裁剪，输出 Rec.709 色域和 sRGB 编码。反射照片到屏幕的适配仍为假设。
