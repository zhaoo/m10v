## 水印数据链

方向由本张 recipe 的 ShootingInfo+0xc8 在原厂任务投递 `0x5351ea9c` 前冻结。原厂 EXIF 映射为 0/1/2/3 → 1/8/3/6。逻辑字形坐标映射回原 Y/C 平面，不旋转整图、不改 EXIF/RAW，不增加整图临时内存。

独立 stamp owner 为 `0x5140..0x5150`，原色彩、RAW 生命周期与 HDF 偏移保持不变。原厂两条预约路径 `0x5351aec4/0x5351b058 → 0x53523e84 → 0x53523db0 → 0x53523e0c` 进入已挂钩 factory，在原构造前清零完整 0x5150 尾部；即使分配器复用相同地址，旧方向也不会残留。

## HDF ADJ 数据链

新增独立函数 ID20，原 ID0..19 的 20 条记录保持原字节。21 条记录的构造长度、19 组表引用、15 组列表消费者、五个列表及 getter 边界均迁移；独立 Node 校验器重建 82 处补丁并检查原记录固定 SHA。新图标为 874。

不自动占用/改写用户五个 ADJ 槽。到相机 **ADJ 模式设定**，将某个槽选为 **HDF 模拟**，四档为关/弱/中/强。MENU 与 ADJ 共用 `M10VHD0.BIN/M10VHD1.BIN` 日志，写入、回读失败会显示错误并与实际可读状态协调。

HDF 缓存位于已有 TopMenu HDF page 的自有尾部；初始化/存档发布发生在 UI 生命周期。真实拍摄任务入口先冻结本张 HDF，再处理色彩缓存；旧预约 Hook 仅清除决定，不提前冻结。拍摄入口无文件读取/写入、分配或等待。关闭/冷缓存采用明确的失败关闭策略。
