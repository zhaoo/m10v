# r14：旧版漏光与老光学链柔化

仅 GR III 2.10 / GR IIIx 1.60。候选测试包，未合并、推送或部署。

用户已实测 r13 的漏光、颗粒、模糊功能正常且响应很快，但否决其视觉还原度。
本轮以该可用链路继续改造漏光与模糊；颗粒算法、参数和纹理保留 r13。
此前功能/速度反馈不代表 r14 新行为已获实机验收，不虚构毫秒指标。

## 历史漏光依据

固定参考提交 `0818cfeb00d92b09c89a68d1795707560343c0de` 的
`native/gr3/film_5207.c`（后续 `a3989d4` 删除软件纹理前的版本）。
原版是平方边缘衰减、固定种子的双线性随机起伏和 RGB screen 曝光：
`out[c] = in[c] + (light * transmission[c] * (255-in[c]) >> 16)`，
transmission 为 256/112/36。亮部增加量递减，纯白不会被染成橙色色块。

- 在电脑构建阶段移植原版 `random32/noise/leak` 的整数计算，保留 uint32 截断、
  负数 `/4` 向零取整、归一化坐标和 seed=5207250d。相机不执行这些像素计算。
- 窄/中/宽映射历史 spread=1/4/8，强度映射历史 gain=2/5/8。
  左右沿用历史画面坐标起伏，双侧采用两次曝光的 screen union。
  保存方向仍由原有横/竖预计算资源选择，不在相机旋转纹理。
- 亮度用随输入递减的 screen 曲线；色度改为先在 ISP 计算
  `spatial_mask * (1-original_luma)`，再分别渗入暖色。
  两次色度调制都读取未提亮的原始 Y，曝光提亮最后执行。
  这是 BT.601 下可分离的近似，不声称逐像素等同历史 RGB 算法。

原版 CPU 成像函数没有接回相机。相机只操作描述符、控制参数与固定小表，
通过原厂 Resize / Granulation 完成所有新增像素处理，无 CPU RNG 或像素回退。
纹理仍为 37 项，驻留 11206656 字节；24MP YUV422 工作区仍为 48000000 字节。
漏光比 r13 增加两次单平面 ISP 混合，不新增整图分配。

## 原厂描述符与安全释放

新增一个精确 preimage 的原厂 Granulation 参数建立钩子，位于 pitch×height 和容量
计算之前。只对私有返回位置及 nonce 绑定的亮度调制调用生效；普通调用和原有纹理
调用执行被替换指令，保留原厂寄存器/状态。

亮度来自原图既有平面，保留 ROI 起点与真实字节 stride；YUV420 每隔一行采样，
对应半高色度。先验证地址、完整 span、容量与源/目标不重叠，再建立原厂加载描述符。
不把 stride 假定为 width，不把未16对齐的合法 ROI 起点移动到另一像素。
原厂容量查询、完成事件、控制器归属、驱动空闲检查和最终释放均保留；
任意步骤失败不得伪造完成或继续 JPEG，不使用超时释放活跃缓冲。

## 模糊资料与实现

参考 [Tiffen 光学扩散指南](https://tiffen.com/pages/diffusion-guide)
对细节柔化、整体对比和高光扩散的区分；参考
[Edmund Optics MTF 说明](https://www.edmundoptics.com/knowledge-center/application-notes/optics/introduction-to-modulation-transfer-function/)
对空间频率与对比传递的说明，以及
[Kodak 胶片技术指南](https://www.kodak.com/content/products-brochures/Film/kodak-essential-reference-guide-for-filmmakers.pdf)。
这些资料支持采用频率响应描述柔化，并不提供本机11个原厂尺度的光学校准值。

新模型是正权重的清晰核心与较宽散射 PSF 叠加，替换 r13 单一高斯衰减。
强度控制核心柔化和散射比例，范围控制较宽部分的半径；保留粗尺度/DC，
避免所有细节一起消失。36组 HDF×强度×范围仍走原厂 Clarity 多尺度滤波；
HDF 原有系数独立组合、关闭模糊时行为不变。不宣称模拟了胶片老化本身、
镜头实测 MTF、非线性高光溢出或光晕。

## 验证与界限

- 历史 `leak()` 从固定提交提取后在电脑编译，多个尺寸、左右及三种范围与新纹理逐点一致。
- 主机假设混合模型下，三档强度的256×256中性阶调/权重组合平均 RGB 误差
  0.59–0.68 DN，最大3–4 DN，纯白变化0。它验证拟合目标，不能证明芯片实际算术。
  高饱和色存在原RGB与可分离YUV的差异，报告单独记录有漏光区域的误差。
- ARM 检查保留照片/工作区未映射和纹理 CPU 访问陷阱；执行实际原厂设置、任务、
  Resize、图提交、回调、释放和 JPEG 交接。驱动/内核端点为服务替身；不冒充物理 DMA、
  ISP 出图、JPEG 文件落盘或相机速度。另覆盖4字节 ROI、不同 stride、上部数据区和420行步进。
- 检查结果、最终 BIN 身份、源码快照与主机报告随包保存，以 final-validation.log 为准。
  全仓既有失败如实保留，不据局部检查声称全仓通过。
- 最终相关回归162项通过；GR III / IIIx最终BIN各12项通过；Node纯ISP检查7项通过。
  全仓484项：411通过、48失败、25跳过，失败名称与r13完全一致。
  build_id：GR III `576243e1`，GR IIIx `ad69b931`。
- 主机色块图的漏光覆盖区域平均RGB误差1.85 DN，最大30 DN；不能用灰阶误差
  代替高饱和色的误差，也不能用模型图代替实机成片。

## 实机对照

使用对应机型包，保留 r13 可用恢复包。先关闭颗粒、HDF及其他效果，固定曝光与白平衡，
分别比较关闭/漏光中档/模糊中档；漏光选有暗部、中灰和白色物体的场景，
模糊选有人像、细纹理与边缘的场景。再检查强度/范围、竖拍、HDF组合及至少连续三张。
比较成片还原度，同时确认即时回放和相册仍正常。主机对比图只作模型说明。
