# GR III 撕纸叠映 R2 真机诊断

仅适用于 GR III 2.10。这是针对 R1 实拍“两张都是普通照片”的诊断版。轮廓原片按设计会保存，第二张才应呈现叠映。离线 ARM 测试能验证执行和交接顺序，真机效果、缓存一致性、耗时和 R1 故障原因待日志确认。

1. 备份 SD 内容。按你安装 R1 的机身流程，使用 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`，完成后关机并移走卡根目录的固件 BIN。如果通过手机测试，同时使用 R2 配套的 `02_SERVICE` 和 GRemote 1.2.9（34）。保留现有自定义启动脚本；只合并所需启动条目。
2. 先用机身复测：保持你遇到问题时的设置，在 **效果 → 撕纸叠映** 按一次 OK 开启。用原快门拍白底深色轮廓，再以相同画幅和方向拍一张实景。两次之间不用操作菜单，等第一张写完再拍第二张。如果结果失败，记下菜单显示的阶段以及第二张文件名即可。
3. 第二张写完后关机。把 **SD 卡根目录下存在的 `M10VMN*.BIN`、`M10VIO*.BIN`、`M10VCP*.BIN`、`M10VAK*.BIN`** 打包回传（每类最多两个，共最多八个）。不必发送照片、胶卷库、脚本或配对信息。日志的固件标识是 `4bd19628`。尽量拍完这两张就取日志，减少滚动覆盖。

GRemote 路径：**相机 → 扩展 → 功能 → 撕纸叠映**。用一个开关开始或取消；拍摄页只显示当前进度。相机完成或报告失败后，开关会回到关闭。对焦和快门仍各自操作。

日志覆盖机身开关、实际拍摄冻结与轮廓/素材阶段、保存的驱动和色调参数、空间处理是否走到及查询状态、描述符与 RAW 归属拒绝、原厂 IIP 完成以及 JPEG 交接。拍摄热路径只把标量写入已有的配方记录区；由已有保存检查点写卡。日志里没有图像像素。合成仍由原厂 ISP/IIP 执行。
