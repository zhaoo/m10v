R3 的真机专用日志显示，第 2 代会话的第一张已取得轮廓阶段，随后被 ISP 执行前的第二次资格检查拒绝（结果 `-5`）。第一次资格检查发生在原厂任务入队前。两次检查之间原厂可修改拍摄信息。R3 日志记录了拒绝分支，未记录哪项字段或状态触发了它。

R4（`7d43faa0`）使用入队时已冻结的逐张资格，执行前仍验证同一 recipe 和拍摄信息的归属、会话世代、待处理阶段、方向、图像布局和 RAW 缓冲区。合成通过原厂 IIP 执行。ARM 回归模拟入队后归一化驱动字段变化，在 R3 复现第一张被拒绝，并在 R4 验证两张分别提交一个和两个 IIP 作业。真机出图仍需复测。

1. 按 R3 的机身流程更新 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`，重启后移走 SD 卡根目录的固件文件。用 GRemote 测试时继续使用 1.2.9，SD 卡安装本包配套的 `02_SERVICE`。

3. 检查第二张是否叠映。如结果有异常，关机后回传 SD 卡根目录实际生成的 `M10VTO0.BIN` 和 `M10VTO1.BIN`。只生成其中一个时，回传该文件即可。
