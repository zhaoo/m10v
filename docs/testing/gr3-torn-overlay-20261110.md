# 撕纸叠映 R1 测试说明

本次交付为 GR III 2.10 实验测试版，搭配 GRemote 1.2.8+33。没有进行相机刷机、SD 写入或真机画质／性能验收，也没有推送或上线。

## 实现与入口

- 机身：效果 → 撕纸叠映 → 开始 / 重新开始。
- 手机：相机 → 扩展 → 功能 → 撕纸叠映。拍摄页显示机身阶段；取消或重开请返回扩展。
- 第一张从白底深色纸片生成亮度蒙版，第二张把实景叠入暗色轮廓。取景为原生画面，首版没有实时合成预览。
- 相机上的复制、阈值转换、Y／UV 混合调用原厂 ISP/IIP。CPU 只管理元数据、任务、曲线和所有权，不执行像素循环、CPU LUT 或 NEON 合成。
- 原厂多重曝光的 MultiBlendProcess 包含 NEON 像素运算，本功能没有复用该合成管线。
- 首版仅接纳 YC422、单张拍摄、相同尺寸和保存方向。HDR、Half、Charmera、像素世界、自定义 LUT 等未获本路线证明的模式不参与本次合成。

## 使用步骤

1. 先备份现有卡文件和固件。按包内目录核对机身固件及配套 SD 服务；不要清空卡上的照片、个人设置或其他插件。只安装 APK 不会给机身增加菜单。
2. 确认机型和基线为 GR III 2.10；本包不适用于 IIIx、IV 或 GR III 2.20。
3. 使用单张拍摄。首轮建议关闭额外纹理效果，保持画幅、方向和胶卷不变，先验证叠映本身。
4. 在明亮、均匀的白底上摆放深色撕纸，开始撕纸叠映。看到「待拍轮廓」后，对焦，再按快门拍第一张。
5. 看到「待拍素材」后，移动到街景、花朵等画面，对焦，再按快门拍第二张。第一张作为轮廓原图保存，第二张 JPEG 为叠映结果。
6. 「合成处理完成」只表示本次原生合成阶段完成，不等于已独立确认 SD 保存成功；进入相册查看实际文件。
7. 取消或开始下一组，请返回扩展或机身效果菜单。普通拍摄不会自动开始新一组。

中途断线后重新读取机身状态，不要反复提交开始。若显示本次未合成，先取消，再以单拍重试；不要用连拍测试两个阶段。已曝光帧不会由之后的菜单选择重新指定效果。

## 必须由真机确认的项目

- 白底是否干净、纸片内部是否填入素材、边缘纤维与过渡是否自然。
- 当前 alpha 端点与舍入未做硅上定量标定；交错色度的邻接亮度权重可能产生细彩边，须检查原尺寸裁切。
- JPEG 与内嵌预览是否一致；RAW 像素不添加叠映，不声称合成 RAW。
- 横拍、竖拍、尺寸或方向改变、取消和重启后恢复普通拍摄。
- 即时回放、相册响应、连续三组单拍拍摄以及 RAW+JPEG 的稳定性；记录卡、画质和候选 SHA。没有实测耗时或速度承诺。

## 恢复

先取消叠映；正常关闭后，缓冲由原厂池释放。若相机不能恢复响应，关机并按既有已确认流程恢复之前的固件／STARTUP.TTL，仅撤除本包 SCRIPT/MCW1101，保留照片、胶卷库与其他插件。不要将此候选用于不可重拍的重要拍摄。
