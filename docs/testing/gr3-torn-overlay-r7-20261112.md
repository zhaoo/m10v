# GR III 2.10 撕纸叠映 R7

R6 真机成片显示，低分辨率二值蒙版放大后产生了明显的台阶和灰边。R7 在固件中保存纸片轮廓到边缘的距离，供 IIP 插值。放大后再用一条短曲线收紧过渡，之后合成当张照片的亮度和色度。现有单拍流程和三款随机轮廓继续使用。额外的 IIP 作业复用同一块蒙版内存，真机边缘和出图耗时待复测。

1. 按原有流程更新本包的 `01_FIRMWARE/SD_ROOT/fwdc239b.bin`。使用手机时继续使用 GRemote 1.2.10，并安装本包配套的 `02_SERVICE`。
2. 进入机身 **效果 → 撕纸叠映** 子菜单，选 **开** 并按 OK。返回取景后，正常按一次快门即可。
3. 可用和 R6 一样的场景检查斜纸边和纸缝。若仍有明显灰边或出图异常，回传成片和 SD 卡根目录实际生成的 `M10VTO0.BIN` 或 `M10VTO1.BIN`。
