## 实现与安全契约

- 效果菜单新增漏光（强度、位置、范围）、颗粒（继承/关闭/弱/中/强、粒径）、模糊（强度、范围）。
  保留原有 HDF 与边框。独立双文件 CRC 设置日志，保存后回读确认。
- 首个真实 processing-task producer 冻结设置、保存 SI 身份与方向；排队后的 UI 变化不影响本张。
- 纹理在构建机生成，设备只运行原厂 ISP Resize、Granulation 与原生空间滤波。
  新增效果无 CPU 像素读取、写入、噪声生成、纹理解压或 CPU 回退。
- 原厂颗粒的 CPU RNG 不满足要求；私有调用跳过 RNG，使用预先生成的相关颗粒场。
  原厂颗粒档位按真实 native 参数反向转换，胶卷槽已有档位保持原语义。
- 顺序为原生 Clarity（组合 HDF 与模糊）、漏光、颗粒。模糊为已验证的原生参数与 Q10 频段系数；
  实际滤波外观仍待相机验收。
- 公开 Resize 的旋转字段在实际 ARM 路径中不生效，未把该字段当作功能使用。
  横向 256×128、纵向 128×256 的平滑漏光场均在构建机生成，按冻结的 EXIF1/8/3/6 选择。
- 工作区按原查询与纹理需求的最大值预留，并保留原查询大小以识别最终图像描述符。
  24MP 漏光为 48,000,000 字节；原分配器另外加入 16 字节余量。
- 完成与释放绑定真实私有调用、图对象、控制器和独立底层服务，检查原服务锁、预约位与驱动状态。
  缺少完成、归属或静止证据时保留资源，不伪造完成，不提前释放。
- 原调用方会忽略部分返回码，所以活动效果失败及编码前完整性检查直接保留等待，阻止半成品进入 JPEG。
  已认证的冷缓存未接入决定与全部关闭时保留原厂路径，包含原厂错误返回。
- ROI 仅规范化私有描述符，检查完整原生缓存跨度不超出原分配；不在 CPU 上裁切图像。
- Pixel/Charmera/HDR 等未接入路径保留既有行为。此次纯 ISP 约束针对新增效果，未移除其他既有 CPU 功能。

固定只读资源为 37 项、11,206,656 字节，SHA-256：
`4e60f0d1b0fb21c5f5e19a9e83264c004f7f1be86a0ef33ab4b688dc61f300a7`。
构建使用 NumPy 2.5.3 与固定种子；资源散列不一致即拒绝出包。

最终 BIN 的活动组合未启用模糊；模糊的冻结、规划、参数、原生描述符与系数由组件测试覆盖。

内核、硬件注册表、寄存器、IRQ 输入、缓存维护及堆服务有明确替身。
