## 原因与范围

- 用户失败任务 `2848f64d01cd6510b56d3bd85643300264fec8dfb0e477ad` 在 `verifying` 阶段约 303 秒失败，服务端错误为“操作已取消”。
- 生产复现任务 `1f477ffa83b4430ea8f9fe27ddc57cb49addd674caed6b87`：GR III 2.10、GRemote、画幅、水平仪、负片颗粒、RAW NR off、HDF、边框与纯 ISP 效果。服务器时间戳显示首次生成约 214 秒，第二次完整重建时在约 303 秒失败。
- `checkedFirmwareJob` 原先将首次生成与完整重建共用同一个五分钟 AbortSignal；第二次构建只剩首轮消耗后的时间。
- 修复为首次生成、独立完整重建各五分钟；单阶段仍有上限。超时统一返回 `M10V_BUILD_TIMEOUT`，网页仅针对该已知错误码显示超时提示，不直接展示内部错误。
