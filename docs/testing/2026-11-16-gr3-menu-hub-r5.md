# GR III 2.10 m10v 菜单 R5 验证

R5 将机身菜单换成定稿的深色列表与暖金焦点。大卡保留原插画并加入分页指示。说明和打赏沿用 R4 原图，两个收款码保留原始像素。胶卷库在现有触控网格上整体下移 12 像素，点胶卷封面启停，点已启用胶卷的片名再按 Fn 打开逐卷设置。Fn 菜单可以调整颗粒、颗粒尺寸和该卷支持的光晕强度。

半格开关每次开机默认关闭。开启后，画幅添加 Half。关闭时，当前使用的 Half 切回 3:2，XPan 等其他画幅保留。GRemote 1.2.13 原有的 Half 开关仍可显式启用 Half。

## 真机检查

1. 先备份现有固件、`M10V/MENU.M10`、胶卷库和 SD 脚本。按照已有 GR III 2.10 刷机流程，将包里的 `04_MENU/SD_ROOT/M10V/MENU.M10` 和 `01_FIRMWARE/SD_ROOT/fwdc239b.bin` 配对使用。刷机完成后关机移走 BIN，保留菜单资源。R4 回退时恢复 R4 固件和原菜单文件。只验证机身菜单时可以保留现有胶卷库。
2. 在 m10v 大卡首页测试横滑和返回。打开打赏并用支付宝、微信分别扫码识别。
3. 胶卷库点已启用胶卷的片名，再按 Fn。保存一个设置值，退出后检查目标胶卷的值、当前拍摄风格和相邻胶卷。再从未启用胶卷验证 Fn 入口。
4. 半格关闭时确认画幅可选 XPan。打开半格后选择 Half，拍一组并检查回放。分别在 Half 和 XPan 生效时关闭半格，检查是否回到预期的画幅。
5. 联测 GRemote 时使用匹配的 SD 服务，验证 App 开启 Half 后机身画幅菜单的读回，并确认拍摄设置的其他入口。
