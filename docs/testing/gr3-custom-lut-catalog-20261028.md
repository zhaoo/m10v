# 自定义 LUT 机内胶卷库缺失修复

基线：GitHub main `8929bdbb43ff2fcb26dadf7eb53ca881c7219603`。该提交对应成功部署 Actions 40526640163；线上 changelog 首项为 2026.10.27.7。

范围：GR III 2.10 / GR IIIx 1.60 共用的胶卷库菜单。按本次用户指令，定向离线验证后直接发布，不做全量回归和实机验收。

## 根因与改动

平台 SD 导出包含 M10VREC2 自定义记录（79..288），但菜单改成精选内建目录后，SD 读取、导航、视图和安装入口都只接受 M10V_DIRECTORY_COUNT 内的内建身份。底层旧分页 API 可读到 LUT，实际菜单无法访问。

保留全部内建位置，在其后按 SD 包顺序追加自定义记录；名称和安装均使用同一目录索引重新查找并校验 expected ID。菜单打开时记录本次目录长度，支持最多 210 款自定义 LUT 和两位数页码。仅供菜单调用；不改变成像、存档 ABI、胶卷编号和 ISP 路径。自定义身份不再被“清理下架胶卷”误删。

## 定向验证

- 新增 host 用例先在原代码观察到导航失败，修复后通过；真实状态库验证浏览零写入、陈旧 ID 拒绝、安装/移除及清理保留自定义卷。
- ARM SD 适配器：稀疏内建包追加两款 LUT，名称与安装身份一致；最高索引/210 款边界、损坏记录拒绝，文件句柄与内存释放检查。
- ARM 视图：执行原厂控件创建/设置/销毁，验证自定义卡片可见、名称产生不同卡面、选中框及 26/26 页码。
- Node：GR3/GR3x 自定义 SD 导出、解析、HTTP 路由及 changelog，共 10 项通过。

额外运行的历史用例 `SdCameraTests.test_custom_lut_installs_into_slot_bank_and_failed_replacement_keeps_active_bank` 仍失败：断言 `M10VC00.bin`，而基线 main 的 persist_custom 已使用 `M079G021.bin` 等不可变记录。此用例还使用早期 104-byte 状态布局；本轮未修改存储逻辑来迎合旧断言。新增用例使用当前目录和真实存储适配器验证。
