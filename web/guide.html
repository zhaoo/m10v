关于 M10V

M10V 是一个非官方 Ricoh GR 固件定制工具，名称来自 GR III 内部 Linux 系统的主机名 m10v。你可以选择胶卷、搭配影像功能，在浏览器工作台生成对应机型的固件。工作台不会自动刷写相机。

支持哪些相机？

  • GR III 2.10 / GR IIIx 1.60：共用工作台，只能选择对应内置来源。下载前核对机身型号和实际版本，不以 Street / Diary / Urban 等机身名称代替固件版本判断；未知内部版本也不要强刷。
  • GR III 2.20 / GR IIIx 1.70：官方周年固件，请先在二阶降级完成对应路线，回到 2.10 / 1.60 后再进入普通工作台。
  • GR IV / GR II：固件导出已暂停。GR II 仍可进入只读检查。

以下说明主要针对 GR III / IIIx。机型不支持的开关不可开启；Half 半格双拍目前仅在 GR III 开放。

怎么使用？

  1. 导入固件：选择站内 GR III 2.10 / GR IIIx 1.60 内置基线。官方固件上传已关闭。
  2. 胶卷与功能：在「胶卷设置」选择胶卷、调整本卷参数；在「影像方案」开启所需功能。开关机画面也在这里，开启后向下展开图片编辑器。
  3. 保存固件：核对方案、阅读风险提示并保存。工作台会自动预检、构建与回读校验，随后下载固件和配置记录。启用胶卷库时，再下载对应机型的配套全量 胶卷库。

新方案除胶卷库外，扩展功能默认关闭。已有本机草稿沿用保存的选择。开启某项代表将该功能加入方案；需要机内选择模式的功能，请继续按下文操作。

胶卷库：选卷、装卷与换卷

GR III 当前有 51 套、IIIx 有 47 套内置胶卷，最多同时启用 10 款。网页支持按分类筛选、搜索、添加和移除。已选胶卷按选择顺序追加在原厂影像控制的 Custom2 后，保留原厂预设；选中一卷后可调整它的参数。

  1. 生成固件后下载配套胶卷包，解压并将 SD/M10V 文件夹复制到卡根目录，与 DCIM 并列。
  2. 打开机内 MENU → 设置 → 胶卷库，方向键移动，按确认键启用或停用胶卷；GR III / IIIx 最多启用十卷。
  3. 回到图像控制选择已装胶卷拍照。升级固件后重新下载匹配胶卷包；更新时只替换胶卷资源文件，保留其他设置文件。

胶卷色彩作用于静态 JPEG；GR III / IIIx 已接入原生 ISP 色调取景。光晕、HDF、边框等效果不提供同等的实时预览；机内 RAW 再开发仍沿用原厂流程。浏览器示意与其他实现不保证逐像素一致。

逐卷胶片效果

GR III 2.10 / IIIx 1.60 可在工作台启用「逐卷胶片效果」，为每款胶卷配置静态 JPEG 效果。机内进入 ADJ → 滤镜，选中已装胶卷后按 FN。颗粒可选关、细、中、粗。漏光可选关、轻、中、强，并可设置位置和范围。模糊可选关、轻、中、强。

光晕同样在 FN 页面调整，800T 和蓝凤凰使用各自的专属光晕。HDF 和边框在 MENU → 设置 → 效果独立设置。逐卷胶片效果当前随 HDF 和边框组件一起构建。

本卷参数与特殊风格

  • 颗粒：启用逐卷胶片效果后，按卷选择关、细、中、粗。Charmera 和方块世界可单独设置，成片效果以实机为准。
  • 800T 与蓝凤凰：保留专属光晕参数，强度、扩散范围和高光阈值为 0–8，强度为 0 时关闭。通用光晕是另外一个可选扩展，详见下文。
  • 模拟曝光 EI：蓝凤凰提供 EI 200 / EI 120；Harman Red 提供 EI 125 / EI 64 / EI 250。这些选项模拟胶卷曝光变化，不改变机身 ISO，也不等同于增感冲洗。
  • Kodak Charmera：可选红、黄、蓝、灰四种双色风格；方块世界提供像素化表现。特殊风格与真实相机／实片的同场景标定仍有边界。
  • 重置质感：恢复该胶卷的质感参数，不改变其他胶卷，也不重置独立的全局 HDF 或模拟曝光 EI。
  • 导入 LUT：在 胶卷库输入名称、导入 sRGB 3D .cube 并导出配套包。机内装卷后使用；自定义 LUT 采用可表达的 ISP 近似，旧自定义胶卷需重新导出，效果与源 LUT 可能有差异。

影像方案：全部扩展功能

统一入口为 胶卷与功能 → 影像方案。开启后在本项下方展开设置，关闭后不再将该项配置加入本次方案。胶卷库仍作为默认基础功能。

裁切焦距 · 两档

用途：将原厂两档数码裁切改成常用焦距。GR III 支持 28–50 mm，默认 35 / 50 mm；GR IIIx 支持 40–71 mm，默认 50 / 71 mm，均按 1 mm 调整。

使用：在影像方案开启「裁切焦距」，填写两档数值。安装本次固件时写入一次，之后可到 MENU → 设置 → 自定义裁切焦距修改：上下选行，OK 编辑，左右调整，OK 保存、MENU 取消。原有裁切操作仍切换关闭和两档。

默认关闭写入，保留机内焦距设置。此开关控制本次更新是否写入预设，并不移除已有固件的机内焦距菜单。数码裁切不改变镜头的物理焦距。

光晕 · 高光溢出与横向拉丝

用途：在亮部增加溢出或横向光线，支持 GR III / IIIx 的胶卷方案。

使用：开启开关并安装固件后，在机内图像控制中选胶卷，按 FN 进入详细设置。光晕模式为 0 关闭 / 1 高光溢出 / 2 横向拉丝，再调整强度、范围和高光阈值。模式按胶卷保存，写入功能后机内初始仍关闭。

800T 保留专属红晕，蓝凤凰保留较弱的橙红模拟；横向拉丝不叠加专属溢出。效果仅作用于静态 JPEG，不显示在取景中，开启可能增加保存与回放等待。

HDF 模拟 · 数字柔焦

用途：为静态 JPEG 增加柔焦和高光扩散，不是物理 HDF 滤镜。

使用：开启后选择关闭、弱、中、强的初始档位；机内通过 MENU → 设置 → HDF 模拟调整，也可在原厂按键自定义的 ADJ 功能列表中分配 HDF。HDF 独立保存，不随换卷、重置胶卷而改变。

支持 GR III / IIIx，可与胶卷库组合；也可在此项下方选择「关闭胶卷库，仅使用 HDF」。独立 HDF 方案不能组合胶卷水印、边框、通用光晕或 A/B 快切。

边框 · 拍立得与 135 胶卷

用途：在照片外增加拍立得或 135 胶卷边框，保留完整构图并扩展画布。

使用：开启并安装后，进入 MENU → 设置 → 效果 → 边框，选择关闭、拍立得或 135 胶卷样式。支持 GR III / IIIx 胶卷方案；网页开关决定是否加入功能，机内再选样式。

时间与胶卷名称水印

用途：将拍摄日期、时间或胶卷名称直接印在 JPEG 上。

使用：开启后选择日期／日期加时间、四种日期格式、四角位置和白／橙／红／黄四种颜色。GR III / IIIx 可单独勾选胶卷名称，即使日期关闭也可保留名称。

机内 MENU → 设置 → 时间水印调整日期、样式；胶卷名称水印菜单独立开关名称。使用本张照片的相机时钟；时钟无效时跳过日期印字，不丢失胶卷效果。GR IV 不提供胶卷名称印字选项。

画幅比例与 Half 半格双拍

用途：增加画幅选择和半透明取景蒙版。GR III / IIIx 提供 4:3、16:9、6x7、XPan；GR IV 对应为 65:24 宽幅。

使用：开启并安装后，在机内拍摄菜单的裁切设置中选择比例，取景蒙版用于构图。请通过实际照片确认所选画幅。

Half 半格双拍仅 GR III：选择 Half 后连续拍摄两张，合成带黑色中央分隔条的双画面，同时保留首张原图。它属于画幅扩展，随画幅开关加入方案。GR IIIx / IV 不显示此项。

原厂负片颗粒

用途：开放原厂负片风格的颗粒选项，与胶卷库的本卷颗粒分开。

使用：开启并安装后，选择原厂负片风格，在图像控制详细设置调整颗粒档位，设置由原厂菜单保存。

RAW 降噪策略

用途：控制写入 DNG 前的 Bayer 降噪，不改变 JPEG 降噪或胶卷颗粒。

使用：开启后在下拉设置中选择原厂策略、关闭 RAW 降噪，或达到指定 ISO 时启用。阈值可选 ISO 400、800、1600、3200、5000、6400、8000、10000、12800。关闭扩展开关后使用原厂策略。

滑轨水平仪

用途：通过横竖滑轨观察左右倾斜和前后俯仰。

使用：开启并安装后，在机内显示水平仪：底部横轨看左右，右侧竖轨看前后；圆点进入中央圆环并变绿时表示水平。此项是取景辅助，不改变照片画面。

A/B 快切

用途：在两种正式影像风格间快速切换，支持原厂风格与已装胶卷配对。

使用：在影像方案开启并安装后，到 MENU 或 ADJ → 影像控制按 DISP，OK 确认 A，再选择另一种风格并按 OK 确认 B，返回取景。取景中短按 DISP 切换；Fn 保留原功能。

MENU 可取消选择；在普通影像控制中选择风格并按 OK，可退出快切；A/B 页松开入口 DISP 后再短按 DISP 也可停用。配对持久保存，重启后快切仍关闭。网页开关关闭时不开放 A/B 选择与快切，保留胶卷功能所需的共享生命周期。

自定义开关机画面

用途：替换相机开机或关机图片，支持 GR III / IIIx。

使用：在影像方案开启「开关机画面」，在下方切换开机／关机标签，上传 JPEG、PNG 或 WebP，调整缩放、左右与上下位置，再点「应用裁切」。最大 20 MB、4000 万像素，输出为 720 × 480。

开机原生图片槽较小，压缩后细节可能减少；关机图替换对应机型的原厂关机请求。请查看压缩预览，实际显示时机仍需机身验证。关闭开关保留图片草稿，但本次导出使用原厂图片；单项「恢复默认」只清除对应图片。

高级扩展 · 调试与版本适配

  • 调试模式：在影像方案的高级扩展中开启。将菜单与拍摄阶段写入 SD 日志，可能增加操作和拍摄等待。仅在排查问题时开启，正常关机后复制日志并附复现步骤；默认关闭。
  • GR IIIx 单包版本适配：仅供明确版本情况的高级使用。默认关闭；可选择仅适配 DSP 包版本，或输入机身记录中的完整 DSP / CPU 四段版本。不要猜测数字；CPU 版本较高时仍可能拒绝更新。

版本适配不能保证其他机型、未知版本或异常恢复；已由导入来源自动处理的适配不会再允许叠加旧方案。

安装、保存与恢复

GR III 固件文件为 fwdc239b.bin，GR IIIx 为 fwdc243b.bin，GR IV 为 fwdc248b.bin。将对应文件放在 SD 卡根目录，按相机官方固件更新流程安装。胶卷资源放入同卡 M10V 目录，不要把胶卷包当作固件刷入。

首次没有有效 M10V 设置记录时使用网页默认值；已有记录优先。新固件不会自动覆盖全部机内胶卷、HDF 或水印设置。裁切焦距的显式一次性写入遵循本次预设；需要调整已有设置时，优先在对应机内菜单操作，不要随意删除存档。

网页草稿自动保存在当前浏览器，支持撤销、重做；它与 SD 卡上的机内设置是不同记录。修改方案会使旧预检结果失效。构建中可取消，生成后保留配置与校验记录。出现异常时停止继续测试，保留官方原包、错误信息和日志；恢复按对应机型的官方流程处理，不能保证所有异常均可恢复。

刷机风险与免责声明

这是非官方修改固件，刷入可能导致无法启动、数据丢失或设备损坏（变砖），可能需要维修，且无法保证恢复。

离线校验、网页构建成功与实际相机验证属于不同证据。部分 GR III 功能已有用户反馈，不能据此推断所有组合、所有机型均已验证。GR IIIx / IV 的覆盖范围以具体候选和实际反馈为准。

请先备份照片、设置与官方固件，确认机型及版本匹配，保持充足电量，再自行评估是否刷入。功能的当前变化与验证状态见更新日志。

下载前：安全刷入步骤

  1. 在相机「设置 → 关于本机 → 固件信息/选项」确认型号与版本。普通 M10V 安装仅限对应的 GR III 2.10 / IIIx 1.60；官方 2.20 / 1.70 请先按二阶降级的独立说明操作。未知来源、未知版本或机型不匹配时停止操作。
  2. 备份照片、设置、官方原包与本次配置/校验记录。准备可靠空 SD 卡，在相机内格式化；先保护唯一副本。
  3. 使用充满电的 DB-110，或理光指定的 K-AC166J 电源适配器。更新期间不要开关机、拔电池/卡或打开卡盖。
  4. GR III 的 fwdc239b.bin 或 IIIx 的 fwdc243b.bin 放在 SD 根目录，只放对应机型的一个更新 BIN；写卡后比对 SHA-256。胶卷资源包不是固件，不能改名互刷。
  5. 相机关机、插卡、关好卡盖，按住 MENU 开机；核对更新界面再选 Execute / 执行。必须等到 Update completed / 更新完成，再关机取卡，不能用固定等待时间代替完成提示。
  6. 重启检查版本、菜单、拍摄、回放、关机与设置保存。删除卡上的更新 BIN，再复制匹配的胶卷资源；保留已有机内设置文件。

更新被拒绝时停止，不要改版本号或反复强刷。若已黑屏、镜头无法回收，且 MENU 更新与回放均不能启动，请保留故障信息并联系维修，不能保证 SD 卡重刷恢复。

官方步骤：理光 GR III · 理光 GR IIIx。官网当前官方更新版本与 M10V 支持版本不同，不要混用。
