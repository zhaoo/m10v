机内操作
  1. 在此生成并按原厂流程安装固件，再到 胶卷库 下载配套文件。
  2. 解压后将 SD/M10V 目录复制到 SD 卡根目录。升级后请重新下载匹配胶卷包。
  3. 机内打开 菜单 → 设置 → 胶卷库，黄色框选择槽位，确认键进入胶卷列表；左右选卷、上下翻页，确认键安装。
  4. 菜单 → 设置 → 时间水印：上下选择高亮行，确认键编辑，左右调整，确认键保存、菜单键取消。
  5. 原影像控制的胶卷设置保留颗粒尺寸、漏光及专属光晕或曝光设置；800T 原厂详细调节继续可用。

800T、胶卷库、颗粒、时间戳与扩展功能中选择的画幅、水平仪、负片颗粒会合入同一固件。胶卷效果仅处理 JPEG；在扩展功能中启用 RAW 降噪策略后，会另外调整写入 DNG 前的 Bayer 降噪。内嵌 JPEG 预览可能带胶卷效果。
