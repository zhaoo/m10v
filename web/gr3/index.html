ONE LAST CHECK

确认你的相机。

请核对机身实际型号、版本与固件来源。操作步骤和免责声明见使用说明。

普通工作台使用 GR III 2.10 / GR IIIx 1.60。官方 2.20 / 1.70 请先二阶降级。

生成后会再次完整重建校验，下载前浏览器还会核对文件摘要；校验失败即停止下载。填写的机身信息不会替代真实设备检查。

  1. 先备份照片、机内设置和官方原包。用相机格式化一张可靠的空 SD 卡；不要格式化唯一的照片或设置副本。
  2. 使用充满电的 DB-110，或理光指定的 K-AC166J 电源适配器。更新期间不要开关机、拔电池、拔卡或打开卡盖。
  3. GR III 使用 fwdc239b.bin，GR IIIx 使用 fwdc243b.bin。将对应 BIN 放在卡根目录；不要混放其他机型的更新包，不要把胶卷资源包当固件。
  4. 相机关机、插卡并关好卡盖。按住 MENU 开机，核对更新界面后选择 Execute / 执行。等待屏幕明确显示 Update completed / 更新完成，再关机取卡。
  5. 重启后检查版本、拍摄与回放，备份本次配置和校验记录。删除卡上的更新 BIN，再按说明复制配套胶卷资源，保留已有机内设置文件。

如更新被拒绝，请停止，不要改名、改版本号或反复强刷。如已黑屏、镜头不回收，且 MENU / 回放均无法启动，请保留原包与故障信息并联系维修；不能保证通过 SD 卡恢复。
