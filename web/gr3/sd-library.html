GR III / GR IIIx · SD 胶卷库

SD 胶卷库

将喜欢的胶卷装进 SD 卡，在机内随时管理最多十款已选胶卷。

需要配套的 M10V SD 胶卷库固件

配套 GR III 2.10 或 GR IIIx 1.60 的 M10V 固件使用。更新固件后，请重新下载匹配的胶卷资源。

新版固件支持胶卷色彩取景；自定义 LUT 需重新导出并在机内重新装入。 本版支持平台47款胶卷，新增「创意」Instax 彩色。取景与 JPEG 使用可表达的 ISP 色彩；颗粒、光晕、水印等成片效果以相机拍摄为准。

选择胶卷

选择胶卷

默认全选，也可只带走喜欢的几卷。卡上的胶卷数量不受十款已选胶卷限制。

自定义胶卷

导入 LUT

独立五胶卷 ISP 拟合工具 →

输入胶卷名称并选择 sRGB 3D .cube。下载时先采样为 13 级色彩表，再离线拟合为取景与 JPEG 共用的 ISP 色彩，结果为近似效果。下载包的 manifest.json 包含配方与误差报告；超出可表达范围时会提示失败。旧自定义胶卷需重新导出并装入才能启用色彩取景，原配置不会自动替换。

安装步骤

放进相机

  1. 解压下载的 ZIP，将 SD/M10V 文件夹复制到 SD 卡根目录，与 DCIM 并列。更新时只替换 FILMS.M10，保留其他文件。
  2. 机内进入 MENU → 设置 → 胶卷库，管理已选胶卷，进入卡上的胶卷列表添加喜欢的胶卷。
  3. 按机内中文提示选择或取消胶卷；已选胶卷按顺序显示，GR III 最多十款。MENU 返回上一级。

GR III 新版测试固件：在 MENU 或 ADJ 的图像控制中，Custom2 后有最多十个独立胶卷位置，原厂预设保留。GR IIIx 保持原有槽位布局。

时间水印：MENU → 设置 → 时间水印，设置日期时间、日期格式、四角位置和文字颜色。胶卷名称：MENU → 设置 → 胶卷名称水印，左右选择开关，OK 保存，MENU 取消。名称可单独开启，与时间水印共用位置和颜色；照片使用胶卷的英文名称。

800T：在影像控制中选中装有 800T 的槽位，按 FN 进入光晕强度、扩散范围、高光阈值、颗粒调节。装入成功后，重启或换卡仍保留。损坏、不兼容或保存失败时保持原槽；不会修改其他槽的质感和时间戳设置。
