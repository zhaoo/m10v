机内怎么选择胶卷？
  1. 在此生成并按原厂流程安装固件，再到 胶卷库 下载配套文件。
  2. 解压后将 SD/M10V 目录复制到 SD 卡根目录。升级后请重新下载匹配胶卷包。
  3. 机内打开 MENU → 设置 → 胶卷库，管理已选胶卷，按中文菜单提示添加或移除胶卷；GR III / IIIx 最多选择十款。
  4. MENU → 设置 → 时间水印：上下选择高亮行，OK编辑，左右调整，OK保存、MENU取消。
  5. 原影像控制的胶卷设置保留原厂颗粒及专属光晕或曝光设置；800T原厂FN详细调节继续可用。

这是独立的候选构建路径，不能与 800T 或工作室其他改动叠加。胶卷效果仅处理 JPEG；在影像方案中启用 RAW 降噪策略后，会另外调整写入 DNG 前的 Bayer 降噪。内嵌 JPEG 预览可能带胶卷效果。
