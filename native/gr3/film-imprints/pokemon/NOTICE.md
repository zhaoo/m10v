# Pokémon character artwork

The four source PNGs are unmodified official Pokédex illustrations downloaded
2026-11-06. They are separate third-party artwork, not covered by this project's
code license. Character names and artwork belong to their respective owners,
including Pokémon, Nintendo, Creatures and GAME FREAK.

- Pikachu: https://assets.pokemon.com/assets/cms2/img/pokedex/full/025.png
- Bulbasaur: https://assets.pokemon.com/assets/cms2/img/pokedex/full/001.png
- Charmander: https://assets.pokemon.com/assets/cms2/img/pokedex/full/004.png
- Squirtle: https://assets.pokemon.com/assets/cms2/img/pokedex/full/007.png
- Reference: https://www.pokemon.com/pokedex/

`7.png` combines these four illustrations into an irregular transparent print
on the build computer. Camera runtime reads only precompiled effect textures.
